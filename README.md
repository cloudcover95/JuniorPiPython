# JuniorPiPython

Python implementation of the original BitNet ecosystem.

Core ternary (1.58-bit) inference, model loading, and tight integration with JuniorAGI_SDK.

## Goals
- Faithful to original BitNet research
- Efficient on edge devices (Pi, Jetson, etc.)
- Shared logic via JuniorAGI_SDK
- Production-grade Python codebase
